## 這是什麼
一個 Claude SKILL。輸入一檔台股（代號或名稱），Claude 會依固定流程查證最新資料，產出一份健檢報告：

- **核心結論**：明確寫買 / 抱 / 賣
- **動作表**：動作、價位、觸發條件
- **六段判斷依據**：價量、技術面、基本面、融資（維持率、追繳價、斷頭賣壓）、法人、事件
- **信心度**：高 / 中 / 低，並說明最大風險

規則：每次重新查最新收盤，不沿用舊數據；查不到就說查不到，不編造。

## 安裝
1. 把整個 `stock-health-check` 資料夾壓成 zip（或直接用本 zip）。
2. 在 Claude 開啟「設定 → 功能 → Skills」，上傳 zip。
3. Claude 需要能上網搜尋（開啟網頁搜尋），才能查最新股價與財報。

## 使用方式
直接對 Claude 說：

- 「健檢 2330」
- 「幫我健檢台積電，成本 950，融資買的」（提供成本會加算損益、停損與移動停損）

## 融資估算公式
- 估算維持率 = 收盤價 ÷（融資成本 × 融資成數）
- 追繳價 = 融資成本 × 融資成數 × 130%
- 斷頭日 = 追繳通知後第 3 個營業日

以上為依公開資料的估算，實際請以券商數字為準。
