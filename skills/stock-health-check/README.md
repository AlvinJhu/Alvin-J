# stock-health-check｜台股個股健檢技能

給 Claude 用的技能（Skill）。輸入「健檢 2330」這類指令，Claude 會依固定流程查證最新收盤、技術面、融資維持率、法人籌碼與重大事件，最後給出明確的**買 / 抱 / 賣**、價位、觸發條件與信心度。

## 用途

- 每次重新查證最新交易日資料，開頭標示「資料基準日」，不沿用舊數據。
- 五個面向固定檢查：價格、技術面、融資、法人、事件。
- 輸出格式固定：核心結論 → 操作表（動作／價位／觸發條件）→ 判斷依據 → 信心與最大風險。
- 若你在對話中提供自己的持股成本，會額外計算損益並區分「停損」與「移動停損」。

## 安裝方式

### 方式一：Claude 網頁版／App

1. 下載本資料夾，壓縮成 `stock-health-check.zip`（zip 內第一層須為 `stock-health-check/SKILL.md`）。
2. 到 Claude「設定 → 功能（Capabilities）→ 技能（Skills）」上傳 zip。
3. 確認技能已啟用。

### 方式二：Claude Code

```bash
mkdir -p ~/.claude/skills
cp -r skills/stock-health-check ~/.claude/skills/
```

重新啟動 Claude Code 後即可使用。

> 技能需要 Claude 能上網查證（網頁搜尋或相關連接器），否則會回報「查不到」而不會編造數據。

## 使用範例

```
健檢 2330
```

```
幫我健檢 2317，我的成本 150
```

輸出示意：

```
資料基準日：YYYY-MM-DD
核心結論：抱，跌破 XXX 減碼。

| 動作 | 價位 | 觸發條件 |
|---|---|---|
| 加碼 | ... | 站回月線且量增 |
| 減碼 | ... | 收盤跌破季線 |

判斷依據：技術…／融資…／法人…／事件…
信心：中。最大風險：…
```
